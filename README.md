# ✂️ Barão Barbearia — Sistema de Agendamentos

![preview](./preview.jpeg)

> Aplicativo mobile completo para clientes realizarem **agendamentos, consultarem horários, serviços e histórico**, enquanto a administração possui controle sobre **agenda e serviços da barbearia**.

O **Barão Barbearia** é um projeto full stack desenvolvido para modernizar o processo de agendamento de uma barbearia, permitindo que clientes realizem seus agendamentos diretamente pelo aplicativo e que a administração gerencie horários e serviços de forma simples e centralizada.

O projeto integra **autenticação, gerenciamento de usuários, agendamentos, histórico, serviços e controle de horários**, conectando o aplicativo mobile a uma API própria e banco de dados MongoDB.

## ⚙️ O que estou aprendendo e construindo

### 🧠 Backend com Node.js, Express e MongoDB

- Criação de **API REST** utilizando Node.js e Express.
- Modelagem de dados utilizando **MongoDB e Mongoose**.
- Autenticação de usuários utilizando **JWT**.
- Criptografia de senhas utilizando **bcrypt**.
- Sistema de usuários com diferentes níveis de acesso:
  - Cliente
  - Administrador

- CRUD completo para os principais recursos do sistema.
- Gerenciamento de:
  - Usuários
  - Agendamentos
  - Serviços
  - Horários disponíveis

- Controle de status dos agendamentos.
- Relacionamento entre usuários e seus respectivos agendamentos.

## 🎨 Design

O aplicativo foi desenvolvido com foco em uma experiência **minimalista, elegante e profissional**, utilizando principalmente:

## 🔐 Segurança

O projeto utiliza algumas práticas importantes de segurança:

- Senhas armazenadas utilizando **hash com bcrypt**.
- Autenticação através de **JWT**.
- Separação de permissões entre clientes e administradores.
- Dados de autenticação armazenados localmente através do AsyncStorage.
- Validação de informações recebidas pela API.
- Controle de acesso baseado na função do usuário.
